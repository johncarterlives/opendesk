# Getting help

| You want to | Go to |
| --- | --- |
| Learn how something works | [docs.opendesk.sh](https://docs.opendesk.sh) |
| Ask a question or share what you built | [Discord](https://dc.opendesk.sh) |
| Report a bug or ask for a feature | [a GitHub issue](https://github.com/useopendesk/opendesk/issues/new/choose) |
| Report a security vulnerability | [a private advisory](https://github.com/useopendesk/opendesk/security/advisories/new), never a public issue. See [SECURITY.md](SECURITY.md) |
| Reach the team directly | `team@opendesk.sh` |

For opendesk Cloud account, billing or outage questions, email `team@opendesk.sh` rather than opening an issue,
and leave out passwords, tokens and customer data.

Want to fix it yourself? See [CONTRIBUTING.md](CONTRIBUTING.md).
